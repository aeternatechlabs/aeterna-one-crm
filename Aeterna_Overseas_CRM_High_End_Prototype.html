Governance and control

Settings & Access

Secure student data and give each team member the access they need.

Suggested roles and permissions

RoleAccessRestrictions
Founder / Super AdminAll branches, reports, settings, integrationsAdmin MFA
Branch ManagerOwn branch leads, staff and reportsNo other branch by default
CounsellorAssigned leads, profiles, tasksNo bulk export / settings
MarketingCampaigns and consented lead recordsNo sensitive student documents
Application OfficerApplicant files and document checklistLimited finance/admin access
AI Agent ServiceExplicitly granted API actionsNo unrestricted database or sends
Security baseline: MFA, branch-level record permissions, encryption in transit/at rest, audit logs, consent tracking, retention/deletion policy, secure document storage, daily backups and tested restore. Keep AI access scoped; do not send sensitive passports, marksheets or financial records to public AI endpoints without approved privacy/security controls.
